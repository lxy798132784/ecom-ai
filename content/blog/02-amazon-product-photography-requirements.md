# Amazon Product Photography Requirements 2026

Amazon rejects thousands of listings every day because of bad product images. Don't let yours be one of them. Here's everything you need to know.

## Amazon's Technical Requirements

Amazon has strict technical specs. Get these wrong and your listing won't go live:

| Requirement | Specification |
|-------------|--------------|
| Main image background | Pure white (RGB 255,255,255) |
| Image format | JPEG (preferred), PNG, TIFF, GIF |
| Minimum size | 1000×1000 pixels |
| Recommended size | 2000×2000 pixels |
| Color mode | sRGB or CMYK |
| File naming | Product ID + variant code + file extension |

## The 7 Image Slots You Should Fill

Amazon allows up to 9 images per listing. Here's what each slot should contain:

1. **Main Image** — White background, product only, fills 85% of frame
2. **Alternate Angle** — Different view of the product
3. **Detail Shot** — Close-up of important features
4. **Scale Reference** — Show product size (next to a common object)
5. **In-Use Shot** — Product being used (lifestyle setting)
6. **Packaging** — What the customer receives
7. **Infographic** — Key features with text overlay

## Common Reasons for Rejection

Amazon will reject your images if:

- Main image isn't pure white background
- Product is on a mannequin (for clothing)
- Image contains watermarks, logos, or borders
- Product occupies less than 85% of the frame
- Includes additional items not included in purchase
- Contains placeholder text like "coming soon"
