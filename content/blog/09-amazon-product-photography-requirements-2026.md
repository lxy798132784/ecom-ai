# Amazon Product Photography Requirements: The Complete Guide (2026)

Amazon has the strictest image requirements of any marketplace. Get them wrong, and your listing gets suppressed. Get them right, and your conversion rate doubles. Here's everything you need to know — plus how AI makes compliance effortless.

## Amazon Main Image Requirements (TECHNICAL)

| Requirement | Specification |
|-------------|---------------|
| Background | Pure white (RGB 255, 255, 255) |
| Product coverage | 85%+ of image frame |
| Format | JPEG (preferred), PNG, TIFF, or GIF |
| Minimum size | 1000 x 1000 pixels |
| Maximum size | 10,000 x 10,000 pixels |
| File naming | Product ID + variant code + extension |
| Borders | No borders, no watermarks, no logos |
| Prohibited | Text, badges, inset images, mannequins |

**Critical**: The white background rule is actively enforced. Amazon uses automated scanning followed by manual review. Non-compliant images get flagged and listings get suppressed.

## Amazon Image Slot Strategy

Each product listing supports up to 9 images (7 slots + main + swatch). Here's how winners use them:

### Slot 1: MAIN IMAGE (White Background)
The most important image. This appears in search results, on detail pages, and in ads. Must be pure white background with product filling 85%+ of the frame.

### Slot 2: Alternate Angle
Show a different angle that reveals features not visible in the main shot. Still on white background.

### Slot 3: Lifestyle / In-Use
Show the product being used. A tent pitched in a forest. A blender making a smoothie. This is where customers connect emotionally.

### Slot 4: Scale Reference
A product shot that helps understand size. Common objects for reference are preferred over measurements.

### Slot 5: Detail / Close-Up
Magnify texture, material quality, stitching, or unique design elements.

### Slot 6: Packaging / What's Included
Show everything the customer receives. Reduces returns from "I thought it came with..."

### Slot 7: Infographic / Features
Highlight key features with minimal text overlays. Amazon allows limited text on secondary images.

### Slot 8: Comparison (Before/After or vs Competitor)
Visual demonstration of value — results, transformation, or side-by-side.

### Slot 9: Brand Lifestyle
Premium lifestyle shot that communicates your brand aesthetic.
